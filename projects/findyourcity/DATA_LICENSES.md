# Source data and licensing

The MIT license in this repository covers the Find Your City application code and original transformation code. It does not relicense third-party source datasets or Python packages.

- **U.S. Census Bureau ACS and Gazetteer data:** U.S. federal government source data. Follow Census attribution and data-use guidance.
- **OurAirports:** released to the public domain by OurAirports. It is supplied without guarantees of accuracy or fitness for use.
- **FAA passenger boarding and airport category data:** U.S. federal government source data.
- **BTS international gateway data:** U.S. federal government source data, published as public domain.
- **Matplotlib Basemap and bundled coastline geometry:** used through the installed Basemap package. Its package and underlying data licenses continue to apply.

The generated locality file contains source fields plus original derived estimates and proxy scores. Anyone redistributing it should retain `DATA_NOTES.md`, `data/source_manifest.json`, and this file so the provenance and limitations remain visible.
